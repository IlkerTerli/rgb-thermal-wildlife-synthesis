# CycleGAN Experiments

This directory documents the CycleGAN experiments used for unpaired
RGB-to-thermal image translation.

The experiments were conducted as part of a bachelor thesis investigating
synthetic and generative approaches for RGB-to-thermal image translation and
wildlife-scene generation.

## Translation Direction

The domain convention used throughout the experiments is:

- Domain A: RGB images
- Domain B: Thermal images
- Translation direction: A -> B

CycleGAN additionally learns the reverse mapping B -> A as part of its
cycle-consistency objective.

## Dataset Configurations

Two dataset configurations were evaluated.

### Small

Dataset structure:

| Split | Domain A (RGB) | Domain B (Thermal) |
|---|---:|---:|
| Train | 400 | 400 |
| Validation | 100 | 100 |
| Test | 100 | 100 |

The Small dataset originated from horizontally concatenated RGB/thermal image
pairs.

For CycleGAN, every pair was split at the horizontal midpoint:

- left half -> Domain A (RGB)
- right half -> Domain B (Thermal)

The reproducible preparation workflow is implemented in:

```text
src/data_preparation/prepare_cyclegan_dataset.py
```

using the `paired` layout.

### Medium

Dataset structure:

| Split | Domain A (RGB) | Domain B (Thermal) |
|---|---:|---:|
| Train | 3000 | 3000 |
| Validation | 375 | 375 |
| Test | 374 | 374 |

The Medium dataset already contained separate RGB and thermal directories.

The following mapping was used:

- `train_rgb` -> `trainA`
- `train_thermal` -> `trainB`
- `val_rgb` -> `valA`
- `val_thermal` -> `valB`
- `test_rgb` -> `testA`
- `test_thermal` -> `testB`

The preparation workflow is implemented in:

```text
src/data_preparation/prepare_cyclegan_dataset.py
```

using the `separated` layout.

## Training Configuration

Both experiments used the same central training configuration.

| Parameter | Value |
|---|---|
| Model | CycleGAN |
| Dataset mode | unaligned |
| Direction | A -> B |
| Epochs | 20 |
| Epoch decay | 0 |
| Batch size | 1 |
| Learning rate | 0.0002 |
| GAN objective | LSGAN |
| Generator | ResNet-9-blocks |
| Discriminator | basic |
| Normalization | instance normalization |
| Load size | 286 |
| Crop size | 256 |
| lambda_A | 10.0 |
| lambda_B | 10.0 |
| lambda_identity | 0.5 |

The complete original configurations generated by the training framework are
preserved in the respective experiment directories.

## Reproducible Dataset Preparation

The reusable dataset-preparation script can be inspected with:

```bash
python src/data_preparation/prepare_cyclegan_dataset.py --help
```

The reusable script separates the preprocessing logic from the archived
experiment metadata and avoids depending on the original machine-specific
paths.

## Evaluation Note

CycleGAN operates on unpaired image domains. Consequently, the generated
thermal-like output does not have a guaranteed pixel-aligned real thermal
target for every generated image.

Pixel-wise full-reference metrics such as PSNR and SSIM are therefore not used
as direct quantitative evaluation metrics for the CycleGAN outputs in this
repository.

The files in this directory are preserved as records of the original
